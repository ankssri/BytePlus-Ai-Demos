# Prompt guides

Drop the Seedream and Seedance 2.5 prompt best-practices PDFs here (e.g.
`seedream_prompt_guide.pdf`, `seedance_2.5_prompt_guide.pdf`).

These reference guides are distilled into the Script Agent's `director_brief`
output and the Seedream prompt composer so generations follow the recommended
prompt structure. Binary guides are for reference only and are not required to
run the app.
