Seedance 2.5 Ad Agent

1 · Brief

Describe the ad. Then let the Script Agent (Seed LLM) turn it into a structured plan, or paste your own plan in step 2.

2 · Ad Plan (script + storyboard)

Review the plan the Script Agent wrote. The director's brief is the single prompt Seedance generates the whole ad from. You can edit the JSON below (e.g. tweak a line, a timing, or the brief) and click Apply plan to save your edits — that's all "Apply plan" does. If you don't edit anything, just continue to Brand Kit.

3 · Brand Kit (omni references)

Build the reference set Seedance keeps consistent across the whole ad: presenter, product, logo, style. Upload, pick an example, or generate with Seedream. Real-person photos are run through Seedream to become model-generated (Seedance-trusted).

Voiceover

4 · Storyboard preview (approval gate)

One card per beat. Each shows an editable keyframe prompt (a clean still — no on-screen text, icons or motion; those are added later). Nothing generates automatically — edit a prompt, then Generate that frame (or Generate all). Then ✎ Edit image (type a fix like "remove the second car"), ↻ Regenerate, and Approve & anchor. "Approved (anchored)" = that frame is passed into the Seedance video as a reference so the final video keeps that exact person and composition. Un-approved frames are ignored.

5 · Generate the ad (Seedance 2.5, one long-form request)

One request generates the whole ad (≤30s) using the director's brief + the Brand Kit + approved storyboard frames as omni references.

6 · Edit, extend & export

Fix a segment in place (timestamp edit) or extend — Seedance edits the generated ad, no re-stitch. Then composite brand overlays in post.
