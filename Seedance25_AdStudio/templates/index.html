Seedance 2.5 Ad Studio

1 · Load the ad script

Pick a bundled sample, or paste/upload your own two markdown files (the script file with the voiceover + shot tables, and the keyframes file with the image + motion prompts).

2 · Generate keyframes with Seedream 5.0 pro

Each shot below shows its start-frame prompt. Generate, then Regenerate (new seed) or Edit (feed the frame back with an instruction) until it looks right. Approve the ones you want to use.

3 · Upload approved keyframes to the Asset Library

Seedance 2.5 reads references from the Asset Library. We register each approved keyframe URL as an Image asset, then poll until it is ready. The resulting asset://<id> is used as the video's first frame.

4 · Generate video with Seedance 2.5

For each shot we create a first-frame image-to-video task. The shot's dialogue is spoken (audio on) so the presenter lip-syncs the matched line.

5 · Assemble the final ad

Collect the per-shot clips in order. If ffmpeg is available on the server, stitch them into one file; otherwise copy the concat command below.
