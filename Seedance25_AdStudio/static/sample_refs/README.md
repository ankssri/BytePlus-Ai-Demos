# Example reference person images

Drop any reference **person photos** here (`.jpg`, `.jpeg`, `.png`, `.webp`).
The app auto-lists every image in this folder on Step 2 as a clickable
"example reference" — pick one and all keyframes are generated locked to that
person's face/outfit (Seedream image reference).

These are only *starting examples*; users can also upload their own image in the
UI without adding it here.

Tip: a clean, front-facing, well-lit full/upper-body portrait works best as a
character reference.
