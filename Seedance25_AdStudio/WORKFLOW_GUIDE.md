# Workflow Guide — Seedance 2.5 Ad Studio

A hands-on run-through of producing one ad from a script.

## 0. Prerequisites
- `.env` filled in (`ARK_API_KEY`, `ARK_AK`, `ARK_SK`, `SEEDREAM_MODEL_ID`,
  `SEEDANCE_MODEL_ID`, `ASSET_GROUP_ID`).
- Models activated on ModelArk (Seedream 5.0 pro, Seedance 2.5).
- `python app.py` → open `http://localhost:5060`. The header badges should show
  **API key ✓ · AK/SK ✓ · Seedream ✓ · Seedance ✓**.

## 1. Load Script
- Choose **`script_A`** (offer-led) or **`script_B`** (lifestyle) from the
  sample dropdown → **Load sample** → **Parse script**. Or upload/paste your
  own two markdown files.
- You'll land on step 2 with one card per shot. Each card shows the matched
  **Hindi dialogue** and the editable **image prompt** (presenter description
  already substituted).

## 2. Generate keyframes (Seedream 5.0 pro)
- Set **Image size** (default `720x1280`, i.e. 9:16).
- **Generate all pending**, or generate per card.
- If a frame is wrong:
  - **Regenerate** (the Generate button re-rolls with a new seed), or
  - **Edit frame** → type an instruction (e.g. *"make the blouse royal blue,
    fix the left hand"*). This feeds the current frame back to Seedream.
- **Approve** each frame you want to keep (green outline). The outro card is
  marked *graphic / post* — build it in your design tool, not Seedream.

> Tip: generate the presenter's first frame, get it right, then reuse that image
> via **Edit frame** on other shots to keep the face/outfit consistent.

## 3. Upload to Asset Library
- Confirm the **Asset group id** (prefilled from `ASSET_GROUP_ID`).
- **Upload all approved**. Each approved keyframe becomes an `Image` asset; the
  app polls `GetAsset` until the status is ready and shows `asset://<id>`.

## 4. Generate video (Seedance 2.5)
- Set **Resolution** (`720p`/`1080p`) and **Duration** (≥ 4 s — Seedance 2.5
  minimum). Keep **Speak dialogue (audio)** checked to have the presenter say
  the line.
- **Create all video tasks**. Each shot creates a first-frame image-to-video
  task (`ratio: adaptive`), and the card polls until the clip is ready, then
  plays it inline.
- Prompt = motion description + the dialogue in quotes. Edit the per-card
  **Video prompt** before creating if you want to tweak the motion.

## 5. Assemble
- **Stitch clips (server ffmpeg)** concatenates finished clips into
  `final_ad.mp4` if `ffmpeg` is on the server's PATH.
- No ffmpeg? Copy the printed concat command and run it locally.
- Add the persistent overlays (Honda/Galaxy Honda logos, red contact bar,
  benefit badges) and the outro card in your editor — these are composited in
  post, not generated by the model.

## Notes & gotchas
- **First frame + audio**: Seedance 2.5 first-frame i2v only supports
  `ratio: adaptive`; the app sets this automatically and uses the frame's aspect.
- **Human faces**: raw face uploads are rejected by Seedance — that's exactly
  why keyframes go through the Asset Library (model-generated images are
  trusted). Keep the presenter AI-generated by Seedream.
- **URL expiry**: Seedream/Seedance output URLs are time-limited (≈24 h for
  video). Register/download promptly.
- **Consistency**: the same presenter description is injected into every image
  prompt; still, re-roll seeds or edit to keep the face/outfit stable across shots.
